# Связь главной с автосимуляторами — 13 октября 2026

## Изменение

Раньше на главной были две ссылки на `/simracing`, обе в подвале. Теперь услуга доступна из основного и мобильного меню, а перед длинной галереей игровых зон расположен отдельный блок «Автосимуляторы в Новокосино». В нём реальные фото клуба, адрес, оборудование, игры и ссылка «Игры и цены автосимуляторов». Цена берётся из общего источника тарифов страницы симрейсинга. Подписи в подвале стали понятными на русском языке.

Блок — серверный компонент; текст и обычный `a[href]` присутствуют в исходном HTML. Это делает связь страниц явной для посетителей и поисковых систем. [Рекомендации Google по внутренним ссылкам](https://developers.google.com/search/docs/crawling-indexing/links-crawlable) поддерживают описательные ссылки в содержательном контексте. Изменение не является гарантией позиций; поисковый эффект после переобхода здесь не измерялся.

## Проверка пяти категорий интерфейса

| Категория / важность | Место | До → после | Причина |
| --- | --- | --- | --- |
| Typography / средняя | Меню | Нет услуги; новый длинный пункт переполнял ширину 768 px → адаптивный кегль и полный текст | Читаемая навигация без обрезания |
| Typography / средняя | Подвал | «КРУГЛОСУТОЧНО» создавало горизонтальный скролл на 1280 px → меньший кегль на промежуточных десктопных ширинах | Устранение переполнения |
| Surfaces / средняя | Главная | Только ссылки в подвале → фотография кокпитов, контрастный разделитель и заметная кнопка | Услуга видна перед галереей зон |
| Animations / низкая | Новая кнопка | Новый элемент → короткий hover/press, отключение перехода и трансформации при reduced motion | Обратная связь без лишней анимации |
| Icons / низкая | Новый блок | Нет блока → флаг и стрелка Lucide с `aria-hidden` | Акцент на гонках и направлении перехода; текст остаётся самостоятельным |
| Performance / средняя | Новый блок | Нет блока → серверный компонент и ленивый WebP 640/1280 px, без нового клиентского состояния | Ограничение стоимости дополнительной секции |

Не применяли: повторяющиеся абзацы с ключевыми словами, отдельный видеоплеер на главной, новую анимационную библиотеку. Для этой задачи достаточно содержательного перехода и существующего дизайна CyberX.

## Проверки

- Playwright: 320, 390, 768, 1024, 1280, 1440, 1920 px. Переполнений страницы и заголовка нет; фотографии загружены; новая кнопка не меньше 56 px, пункты меню не меньше 44 px.
- Переходы из нового блока и мобильного меню открывают `/simracing`; закрытие меню и переход к десктопной ширине снимают блокировку прокрутки.
- У новой кнопки видимый клавиатурный фокус; reduced motion отключает переход.
- Axe WCAG A/AA/2.1 AA для нового блока: 0 нарушений. Это не аудит доступности всей существующей главной страницы.
- Исходный HTML содержит блок и ссылку; ошибок JavaScript в проверенном сценарии нет.
- ESLint изменённых файлов и отдельная проверка TypeScript главной с её импортами прошли.
- Production build: успешно, 44 статические страницы. Существующая настройка пропуска lint/types при сборке не менялась; проверки выполнены отдельно.

Локальные снимки и протоколы: `output/playwright/simracing/home-*` (игнорируются Git). Lighthouse и позиции в поиске повторно не измерялись.
