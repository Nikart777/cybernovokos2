# Подарочные сертификаты: запуск оплаты

Страница: `https://cyberx-novokosino.ru/certificate`. Код: `components/certificate-drop/`,
сервер: `lib/gift-drop/`, API: `app/api/gift/*`. Старая версия лежит в `archive/certificate-2026-10-17/`.

## Как это работает

1. Покупатель собирает сертификат и платит картой или СБП на странице ЮKassa.
2. После подтверждения оплаты сайт сам генерирует промокод (7 символов, буквы и цифры)
   и сохраняет заказ в `.gift-data/` (папка не попадает в git).
3. Админу в Telegram приходит сообщение с промокодом и номиналом:
   **этот промокод нужно завести в Langame Новокосино на ту же сумму.**
4. Покупатель видит промокод и ссылку-сюрприз на странице заказа и получает письмо.

## Переменные окружения на хостинге

| Переменная | Значение |
|---|---|
| `YOOKASSA_SHOP_ID` | `1498570` |
| `YOOKASSA_SECRET_KEY` | секретный ключ из кабинета ЮKassa → Интеграция → Ключи API (в git не класть) |
| `YOOKASSA_TEST_MODE` | `false` для боевого магазина (`true` для тестового) — необязательно, включает доп. проверку |
| `YOOKASSA_TAX_SYSTEM_CODE` | `2` — УСН «доходы» (по умолчанию уже 2) |
| `YOOKASSA_VAT_CODE` | `1` — без НДС (по умолчанию уже 1) |
| `GIFT_RECEIPT_PAYMENT_MODE` | `full_payment` — полная оплата (по умолчанию) |
| `GIFT_RECEIPT_PAYMENT_SUBJECT` | `payment` — пополнение баланса (по умолчанию) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | уже используются сайтом; `GIFT_TELEGRAM_CHAT_ID` — если уведомления нужны в другой чат |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` | уже используются сайтом, нужны для письма покупателю |

Пока нет `YOOKASSA_SECRET_KEY`, на боевом сайте вместо оплаты покажется
«Онлайн-оплата временно недоступна» со ссылкой на Telegram. Тестовая кнопка оплаты
есть только в режиме разработки (`npm run dev`).

## Кабинет ЮKassa

- HTTP-уведомления: `https://cyberx-novokosino.ru/api/gift/webhook`,
  события `payment.succeeded` и `payment.canceled`.
- Чеки 54-ФЗ: включить «Чеки от ЮKassa» (или указать `GIFT_RECEIPTS=false`, если чеки бьёт своя касса).

## Хранилище

Заказы и загруженные фото лежат в `.gift-data/` в корне сайта (можно перенести через
`GIFT_DATA_DIR`). При переустановке сайта эту папку нужно сохранять.
