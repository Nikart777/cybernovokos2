# 🔐 Инструкция по управлению ценами

Административная панель CyberX Novokosino позволяет редактировать цены на сайте без изменения кода. Все данные хранятся в файле `data/prices.json`.

---

## 📋 Быстрый старт

### 1. Доступ к админке

**URL**: `https://cyberx-novokosino.ru/admin/prices`  
**Локально**: `http://localhost:3000/admin/prices`

При первом входе вам потребуется ввести пароль администратора.

> [!IMPORTANT]
> Пароль хранится в переменной окружения `ADMIN_PASSWORD`. Убедитесь, что она установлена в `.env.local` (локально) или в настройках деплоя на Rusonix.

---

## ✏️ Редактирование цен

### Структура данных

Админка позволяет управлять тремя типами контента:

#### 1. **Игровые зоны** (Zones)
Каждая зона содержит:
- Название зоны (например, "Общий зал", "VIP Bootcamp")
- Категории тарифов (например, "Будни", "Выходные")
- Отдельные тарифы с временем и ценой

#### 2. **Абонементы** (Abonnements)
Специальные предложения с ценами для разных зон:
- Название абонемента (например, "Сутки", "50 часов")
- Цены для каждой зоны:
  - **Общий зал** (Common)
  - **VIP Bootcamp** (VIP)
  - **SOLO** (Solo)

#### 3. **Категории тарифов**
Группировка тарифов по времени суток или типу:
- Будни / Выходные
- Ночные тарифы (отмечаются специальным бейджем)

## 🎯 Как редактировать

### Изменение существующих цен

1. Откройте админку по адресу `/admin/prices`
2. Введите пароль
3. Найдите нужную зону или абонемент
4. Кликните на поле с ценой или названием
5. Внесите изменения
6. Нажмите **"Сохранить"** в верхней части страницы

### Добавление новых элементов

- **Новая зона**: кнопка "+ Добавить зону"
- **Новая категория**: кнопка "+" рядом с категориями
- **Новый тариф**: кнопка "+" внутри категории
- **Новый абонемент**: кнопка "+ Добавить абонемент"

### Удаление элементов

Нажмите на иконку **🗑️ корзины** рядом с элементом, который хотите удалить.

### Ночные тарифы

Кнопка **"НОЧЬ"** помечает тариф как ночной. На сайте такие тарифы отображаются с темным фоном и специальным бейджем 🌙.

## 💾 Сохранение изменений

### Что происходит при нажатии "Сохранить"

1. Данные отправляются на сервер через API `/api/prices` вместе с паролем (заголовок `X-Admin-Password`); без верного `ADMIN_PASSWORD` сервер отвечает 403 и ничего не пишет
2. Файл `data/prices.json` обновляется на сервере
3. Изменения **мгновенно** отображаются на странице `/prices`

### ⚠️ Важно для продакшена

> [!WARNING]
> Изменения через админку применяются только на **текущем сервере**. При следующем деплое из GitHub они могут быть перезаписаны старой версией из репозитория.

**Рекомендуемый workflow**:
1. Внесите изменения через админку
2. Скачайте обновленный `data/prices.json` с сервера
3. Закоммитьте его в репозиторий:
   ```bash
   git add data/prices.json
   git commit -m "Update prices via admin panel"
   git push
   ```

Либо вносите изменения **локально** через админку, затем сразу коммитьте и пушьте.

## 🆘 Частые вопросы

**Q: Я изменил цены, но они не отображаются на сайте**  
A: Убедитесь, что нажали кнопку "Сохранить". Проверьте консоль браузера на наличие ошибок.

**Q: После деплоя мои изменения пропали**  
A: Это нормально. Деплой перезаписывает файлы из GitHub. Закоммитьте `data/prices.json` в репозиторий.

**Q: Забыл пароль от админки**  
A: Пароль хранится в переменной окружения `ADMIN_PASSWORD`. Проверьте `.env.local` или настройки хостинга.

**Q: Как добавить новую зону?**  
A: Нажмите "+ Добавить зону" внизу списка зон, заполните название и добавьте категории с тарифами.
